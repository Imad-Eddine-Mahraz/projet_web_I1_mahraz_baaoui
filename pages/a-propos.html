Le projet

FitZone est un site fictif de salles de sport, réalisé en binôme en HTML5, CSS3 et JavaScript natif (sans framework ni bibliothèque), dans le cadre du module TI504N - TI504NB à l'EFREI.

  • Design responsive avec media queries, grille CSS Grid et menu burger sur mobile.
  • Carrousel, barre de progression, compteurs déclenchés au scroll, filtres et simulateur de prix en JavaScript.
  • Réservation de cours persistante via localStorage et pré-remplissage intelligent du formulaire via URLSearchParams.
  • Scripts chargés avec defer et isolés par des blocs try/catch pour garantir l'affichage du contenu.
  • Pages validées avec les validateurs HTML et CSS du W3C et code versionné sur GitHub.
